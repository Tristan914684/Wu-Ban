# Architecture decision records

**Status:** Active index  
**Owner:** Engineering lead  
**Reference when:** Making or revisiting a structural, data, runtime, or
integration decision.  
**Agent obligation:** Accepted ADRs are immutable. Add a superseding ADR rather
than editing the decision or its original rationale.

## Statuses

- **Proposed:** Open for review; not binding.
- **Accepted:** Binding.
- **Superseded:** Historical; replacement ADR is linked.
- **Rejected:** Considered and not selected.
