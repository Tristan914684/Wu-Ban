# Glossary

**Status:** Binding vocabulary  
**Owner:** Product design  
**Reference when:** Naming code, data fields, UI copy, decks, and tests.  
**Agent obligation:** Use canonical terms; do not introduce medicalised aliases.

- **舞伴 (Wǔbàn):** Player-facing product name.
- **DanceBros:** Repository and internal project name.
- **Player:** Adult using the game. Prefer over patient, subject, or senior.
- **Supporter:** Player-approved family member or caregiver.
- **Primary player:** The single calibrated person whose movement owns a session.
- **Companion:** Unscored person dancing nearby.
- **Cue:** Timed instruction for an allowed movement or hold.
- **Chart:** Versioned list of cue times and safe movements for a track.
- **Move event:** Domain representation of an observed movement.
- **Scoreable frame:** Pose frame that passes confidence, visibility, identity,
  and calibration gates.
- **Fun score:** Immediate Beat, Shape, Flow, and Memory feedback.
- **Session measure:** Derived, non-clinical gameplay value.
- **Trend-valid session:** Completed session allowed into longitudinal analysis.
- **Personal baseline:** Player-specific reference built from valid sessions.
- **Movement-and-attention trend:** Public term for longitudinal gameplay
  patterns. Do not call it a cognitive profile.
- **Check-in:** Non-diagnostic suggestion sent to a consented supporter.
- **Health alert:** Clinical or urgent notification; not part of the MVP.
- **Simulated history:** Seeded demo data, always visibly labelled.
- **Pose provider:** Replaceable adapter that estimates landmarks from frames.
- **Quality gate:** Rules deciding whether a frame or session may be scored.
- **Miora provenance:** Prompts, variants, edits, licence context, and final use
  for an AI-created visual.
